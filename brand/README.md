# Brand images

`icon.png` (256×256) and `icon@2x.png` (512×512) are the integration's icon: an original
design, not a vendor logo. Home Assistant shows custom integration icons from the
[home-assistant/brands](https://github.com/home-assistant/brands) repository, so these files
are submitted there as `custom_integrations/aerohive_local/icon.png` and `icon@2x.png`.
See [Development → Getting listed in HACS](../docs/development.md#getting-listed-in-hacs).
